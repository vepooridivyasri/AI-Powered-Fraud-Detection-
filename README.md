AI-Powered Credit Card Fraud Detection
📌 Overview

A machine learning project that detects potentially fraudulent credit card transactions using a Random Forest Classifier.

🛠️ Technologies
- Python
- Pandas
- Scikit-learn
- Random Forest
- Joblib
- Streamlit

🔍 Features
- Data preprocessing
- Random Forest model training
- Model evaluation using Accuracy, Precision, Recall and F1-score
- Real-time fraud prediction using Streamlit

🚀 Run the Project

pip install -r requirements.txt
streamlit run app.py

📁 Files

- "fraud_detection.py" — Model training and evaluation
- "app.py" — Streamlit application
- "random_forest_model.pkl" — Trained model
- "requirements.txt" — Required libraries
